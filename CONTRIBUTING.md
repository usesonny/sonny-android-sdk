# Contributing

Use [issues](https://github.com/usesonny/sonny-android-sdk/issues) for reproducible bugs and feature requests. Include your SDK commit/version, OS version, and a minimal example. Keep identity JWTs, device tokens, provider keys and customer data out of public reports.

Changes should preserve the existing hosted widget and versioned bridge. Keep native code focused on platform presentation, lifecycle, storage, permissions owned by the host app, and notifications. Add a focused regression test for behavior changes and run the checks in the README before opening a pull request.

By contributing, you agree that your contributions are licensed under the MIT license.
